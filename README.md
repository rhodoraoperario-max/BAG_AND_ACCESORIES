# 👜 BAG & ACCESSORIES SHOP
### Inventory Management System

## 📌 Project Description

The **Bag & Accessories Shop Inventory Management System** is a console-based application developed using C++. It is designed to help manage and organize the products of a bag and accessories store.

The system allows users to display, search, add, update, delete, sell, and restock products. It also provides price sorting, low-stock monitoring, and inventory summaries.

This project aims to make inventory management easier, faster, and more organized.

## ⚙️ System Features

The system has ten main features:

| No. | Feature | Description |
|---|---|---|
| 1 | Display Products | Displays all available products and their details. |
| 2 | Search Product | Searches for a product using its ID. |
| 3 | Add Product | Adds a new product to the inventory. |
| 4 | Update Product | Updates product name, brand, price, or stock. |
| 5 | Delete Product | Removes a product from the inventory. |
| 6 | Sell Product | Calculates the total amount and deducts sold items from stock. |
| 7 | Restock Product | Adds additional quantities to existing products. |
| 8 | Sort Products by Price | Arranges products from lowest to highest price. |
| 9 | Low Stock Products | Displays products with five or fewer remaining stocks. |
| 10 | Inventory Summary | Displays total product types, total stock, and inventory value. |

## 📖 Scope and Delimitation

### Scope
The system focuses on managing the inventory of a bag and accessories shop. It includes product information management, searching, adding, updating, deleting, selling, restocking, sorting, low-stock monitoring, and inventory summaries.

### Delimitation
- The system is console-based and uses a text interface.
- It does not support online ordering or online payments.
- It does not include customer accounts or delivery tracking.
- It does not use a database.
- Product information and changes are stored temporarily while the program is running.
- The system is intended for basic inventory management only.
